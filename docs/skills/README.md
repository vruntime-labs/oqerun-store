# Oqerun Store project skill pack

This folder contains project-local adaptations of the user's ChatGPT working skills. These are Markdown instructions for AI-assisted development and human contributors. They are not executable scanners, GitHub Actions, IDE extensions, or installed third-party packages.

## Included
- [ChatGPT Taste Skill](CHATGPT_TASTE_SKILL.md): product-specific design direction and taste.
- [ChatGPT Impeccable](CHATGPT_IMPECCABLE_SKILL.md): interface quality, accessibility, and implementation standards.
- [ChatGPT VibeSec](CHATGPT_VIBESEC_SKILL.md): defensive application-security workflow.
- [ChatGPT Memory Kit](CHATGPT_MEMORY_KIT.md): project continuity and factual session records.

The full original Taste and Impeccable source documents were not available in the project file set at import time. Their project adaptations are based on the user's recorded requirements and activation instructions; they are not represented as byte-for-byte copies of the originals. Replace these adaptations with the originals if the user supplies them.

The root [AGENTS.md](../../AGENTS.md) is the concise entry point and applies these rules to repository work.
